# BONUS Music 🎵

> Votre musique, votre manière de l'écouter.

BONUS Music est un lecteur de musique Android conçu avec une interface inspirée de Samsung One UI.

## ✨ Fonctionnalités

- 🎵 Lecture de musique locale
- 🔔 Contrôles de lecture depuis la notification
- 🎧 Support des appareils Bluetooth
- 📚 Bibliothèque musicale
- 🔎 Recherche dans les titres, artistes et albums
- 🎨 Interface inspirée de One UI
- 🔄 Système de mise à jour intégré
- 📱 Interface adaptée à Android moderne

## 🚧 Développement

BONUS Music est actuellement en développement mais vous pouvez toujours utiliser l'application. Il est actuellement compatible avec tous 
les smartphones sous Android 13 ou version ultérieure.

## Que faire si je n'arrive pas à télécharger l'application ? 
L'application n'a pas été approuvée par Play Protect. Si vous n'arrivez pas à installer l'appli, assurez vous d'avoir sélectionné le fichier
.apk (et non pas .zip), appuyez sur le fichier, et puis, si un pop-up s'affiche, appuyez sur plus d'infos -> installer quand même. L'appli
n'a pas de virus, elle est donc sans danger. Si ça bloque avant et que vous avez un smartphone Samsung sous One UI 6.0 ou ultérieur, allez dans
Paramètres -> Sécurité et confidentialité -> Bloqueur automatique et désactivez cette option. Cela permettra d'installer des applications inconnues.
